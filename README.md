# SaiKet Systems Python Development Internship Projects

This repository contains six Python projects completed as part of the **SaiKet Systems Python Development Internship**.

The projects demonstrate Python fundamentals, object-oriented programming, file handling, exception handling, web scraping, API integration, input validation, and basic text analysis.

## Completed Tasks

### 1. To-Do List Application

A terminal-based application for adding tasks, viewing tasks, and marking tasks as completed. It uses a Python class and dictionaries to manage task information.

### 2. Guess the Number Game

A game that generates a random number between 1 and 100. It provides higher and lower hints, validates user input, and counts valid attempts.

### 3. Basic File Handling

A program that reads a text file, finds and replaces a specified word, and saves the modified content. It includes input validation and file-related exception handling.

### 4. Basic Web Scraper

A web scraper using Requests and Beautiful Soup to retrieve and display public headlines from the Hacker News website.

### 5. Currency Converter

A terminal-based currency converter that retrieves exchange-rate data from the public Frankfurter API and performs currency conversion with input and error handling.

### 6. Word Count Tool

A text-analysis tool that counts lines, words, and characters and performs case-insensitive word-frequency analysis.


## Running the Projects

Clone the repository:

```bash
git clone https://github.com/madhuamarappanavar007-del/saiket-python-internship.git
```

Open the project folder:

```bash
cd saiket-python-internship
```

### Task 1

```bash
python task_1_todo_list/todo_list.py
```

### Task 2

```bash
python task_2_guess_number/guess_number.py
```

### Task 3

```bash
cd task_3_file_handling
python file_handling.py
cd ..
```

### Task 4

```bash
python task_4_web_scraper/web_scraper.py
```

### Task 5

```bash

```

```bash

```
